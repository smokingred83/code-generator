# code-generator
A RAG-powered code generation application that combines retrieval-augmented generation with embedding-based search to generate code from natural language prompts.

This project is inspired by the open-source project [LLM Engineer's Handbook](https://github.com/PacktPublishing/LLM-Engineers-Handbook) by [Paul Iusztin](https://github.com/iusztinpaul) and [Maxime Labonne](https://github.com/mlabonne). Portions of the structure and ideas were adapted under the MIT License.
